# Customer Feedback AI System

## Overview

This project analyzes customer feedback using a neural network-based NLP model and recommends appropriate business actions.

## Features

* Sentiment classification (Positive/Negative)
* AI-driven decision system
* Memory-based response adaptation
* Modular AI pipeline

## Tech Stack

* Python
* PyTorch
* NLP (Embeddings, LSTM)
* Basic AI Agent Logic

## How It Works

1. Input customer feedback
2. Preprocess text
3. Predict sentiment using trained model
4. Apply decision logic
5. Return action recommendation

## Example

Input:
"This product is not good"

Output:
{
"sentiment": "Negative",
"action": "Flag for review"
}
